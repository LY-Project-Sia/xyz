# LYNNARD.AQ — Professional Terminal Portfolio

Reworked from the supplied portfolio into a professional operations/terminal aesthetic.

## Visual direction

- Black-first interface
- `#00FF00` matrix/terminal green
- Glowing amber `#FFBF00`
- Controlled red alerts/accent
- Monospaced typography
- Grid background and scanline texture
- Console panels, status indicators and system metrics
- Responsive desktop/tablet/mobile layout

## Files

- `index.html` — complete portfolio
- `style.css` — professional terminal design
- `script.js` — typing terminal + active navigation

No framework or build step is required. Open `index.html` directly or serve the folder from any static web server.

The content preserves the major portfolio themes from the original: project management, web development, education systems, civic technology, sustainability, student performance, attendance tools and Arduino/IoT concepts.
